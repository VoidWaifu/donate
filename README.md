## Что это?

Страница для поддержки автора проектов **VoidWaifu**. Здесь собраны все доступные способы доната в одном месте.

## Способы поддержки

- ⭐ **Telegram Stars** — поддержать посты в канале
- ₿ **Bitcoin** — сеть BTC
- Ξ **Ethereum** — сеть ETH (ERC20)
- ₮ **Tether (USDT)** — сеть ERC20
- 💎 **Toncoin** — сеть TON
- ◆ **Polygon** — сеть Polygon (ERC20)

## Возможности

- ✅ Копирование адресов в один клик
- ✅ Анимированный звёздный фон
- ✅ Тёмная тема с неоновыми акцентами
- ✅ Адаптивный дизайн
- ✅ Работает прямо в браузере

## Технологии

Чистый **HTML + CSS + JavaScript**. Никаких серверов — всё работает локально в браузере.
